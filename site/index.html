How joining works

  1. Scan the code.
    Point a phone camera at the QR. A laptop opens the join page and shows one line to paste.
  2. Install and open.
    The page downloads the app, then "Open in the app" fills in the network for you.
  3. Type the code.
    The host reads out a 6-digit code from their join desk. Enter it, and you are online.
